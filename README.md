# Password Security Assistant

A web-based password security analyzer and password generator built using HTML, CSS and JavaScript.

## Live Demo

https://guruknt17july-png.github.io/password-security-assistant/

## Features

- Password strength analysis
- Strong password generation
- Password security recommendations
- Copy generated password
- User-friendly interface
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## Project Structure

Password-Security-Assistant/
- index.html
- style.css
- app.js

## How to Run

Open `index.html` in a browser or use VS Code with Live Server.
